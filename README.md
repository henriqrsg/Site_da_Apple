# Apple iPhone 17 Website Clone

Projeto de um site inspirado na página oficial de lançamento do iPhone 17, desenvolvido utilizando **React** e **TailwindCSS**, com foco em design moderno, performance e fidelidade visual à identidade da Apple.

## Objetivo

Este projeto foi criado com o intuito de praticar:

* Construção de interfaces modernas com React
* Estilização eficiente utilizando TailwindCSS
* Reprodução fiel de layouts de alto padrão (UI Clone)
* Componentização e reutilização de código
* Estruturação de aplicações front-end escaláveis

## Tecnologias Utilizadas

* React
* TailwindCSS
* JavaScript
* Vite

## Funcionalidades

* Página inicial inspirada no lançamento do iPhone 17
* Seções de apresentação do produto (design, performance, câmera)
* Layout responsivo para diferentes dispositivos
* Animações suaves e transições modernas
* Navbar fixa com navegação entre seções
* Organização visual semelhante ao padrão Apple

## Destaques Técnicos

* Uso de **componentes reutilizáveis** no React
* Estilização 100% baseada em **TailwindCSS** (utility-first)
* Layout responsivo com abordagem mobile-first
* Código limpo e modularizado
* Otimização de performance com Vite
* Estrutura escalável para expansão futura

## Aprendizados

Durante o desenvolvimento deste projeto, foram reforçados conceitos como:

* Separação de responsabilidades em aplicações React
* Uso estratégico de classes utilitárias para acelerar o desenvolvimento
* Construção de interfaces altamente polidas
* Organização de projetos front-end modernos
